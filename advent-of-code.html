Qué es

Advent of Code es un calendario de retos de programación que se publica cada diciembre. La edición de 2025 tiene 12 días, y cada día plantea un problema con dos partes: la segunda cambia las condiciones de la primera y a menudo obliga a buscar otra técnica. El día 12 solo tiene una parte.

Cada parte está resuelta en un script independiente que solo usa la biblioteca estándar de Python. En total son 23 scripts y unas 2.200 líneas.

Día 3, parte 2 · Selección voraz con una pila

dia03/parte2.py

De cada fila de dígitos hay que quedarse con 12, sin cambiar su orden, de forma que el número resultante sea el mayor posible. Probar todas las formas de elegirlos no es viable.

La solución recorre la fila una sola vez con una pila. Mientras queden dígitos que se puedan descartar y el dígito nuevo sea mayor que el de la cima, saca la cima: un dígito grande siempre vale más cuanto más a la izquierda queda. Al terminar se queda con los 12 primeros de la pila.

vidas_para_borrar = len(linea) - longitud_objetivo
pila = []

for digito in linea:
    while vidas_para_borrar > 0 and pila and pila[-1] < digito:
        pila.pop()
        vidas_para_borrar -= 1
    pila.append(digito)

pila_final = pila[:longitud_objetivo]

Día 8 · Union-Find

dia08/parte1.py · dia08/parte2.py

La entrada es una lista de puntos en tres dimensiones. Se calcula la distancia entre todos los pares, se ordenan de menor a mayor y se van uniendo los puntos más cercanos en grupos. La parte 1 pide el producto de los tamaños de los tres grupos mayores tras las 1.000 uniones más cortas; la parte 2, seguir uniendo hasta que queda un solo grupo.

Para saber en cada paso a qué grupo pertenece un punto se usa una estructura Union-Find con compresión de ruta y unión por tamaño. Las distancias se comparan al cuadrado, sin calcular raíces.

def find(self, i):
    if self.parent[i] != i:
        self.parent[i] = self.find(self.parent[i])  # Compresión de ruta
    return self.parent[i]

def union(self, i, j):
    root_i = self.find(i)
    root_j = self.find(j)

    if root_i != root_j:
        # Unimos el grupo más pequeño al más grande
        if self.size[root_i] < self.size[root_j]:
            root_i, root_j = root_j, root_i
        self.parent[root_j] = root_i
        self.size[root_i] += self.size[root_j]
        return True
    return False

Día 10, parte 2 · Eliminación de Gauss-Jordan

dia10/parte2.py

Cada máquina tiene varios contadores y varios botones; cada botón suma uno a unos contadores concretos. Hay que encontrar el menor número de pulsaciones que deja todos los contadores en su valor objetivo. En la parte 1, con luces que se encienden y se apagan, bastaba con probar combinaciones de botones; con contadores, cada botón puede pulsarse muchas veces.

El problema se plantea como un sistema de ecuaciones lineales: una ecuación por contador y una incógnita por botón, que es el número de veces que se pulsa.

  • • Reducción: la eliminación de Gauss-Jordan deja cada incógnita con pivote expresada en función de las que no lo tienen, las variables libres.
  • • Búsqueda: se prueban valores para las variables libres en orden creciente de su suma. Para cada combinación se calcula el resto de las incógnitas, y solo vale si todas son enteras y no negativas.
  • • Poda: una combinación deja de ampliarse cuando la suma de sus variables libres ya alcanza el mejor total encontrado.

Día 11, parte 2 · Caminos en un grafo dirigido

dia11/parte2.py

Hay que contar los caminos entre dos nodos de un grafo dirigido que pasan por otros dos nodos obligatorios. Enumerarlos uno a uno no escala.

Los caminos entre dos nodos se cuentan con una búsqueda en profundidad que recuerda el resultado de cada nodo, de modo que cada uno se calcula una sola vez. Para obligar a pasar por los dos nodos intermedios, el recorrido se parte en tres tramos y se multiplican los caminos de cada tramo. Como los nodos obligatorios pueden visitarse en dos órdenes, se suman las dos opciones.

# Opción A: svr -> dac -> fft -> out
total_A = contar_entre("svr", "dac") * contar_entre("dac", "fft") * contar_entre("fft", "out")

# Opción B: svr -> fft -> dac -> out
total_B = contar_entre("svr", "fft") * contar_entre("fft", "dac") * contar_entre("dac", "out")

total_final = total_A + total_B

Fragmento resumido: en el script, cada tramo se guarda antes en su propia variable.

Cómo ejecutarlo

Hace falta Python 3.10 o superior. Las entradas no están en el repositorio, porque Advent of Code pide no redistribuirlas: cada uno descarga la suya desde la página del reto y la guarda como entrada.txt en la carpeta del día.

python dia01/parte1.py                # lee dia01/entrada.txt
python dia01/parte1.py otro.txt       # o el fichero que le indiques

Todas terminan en pocos segundos, salvo el día 12, que tarda alrededor de un minuto.
